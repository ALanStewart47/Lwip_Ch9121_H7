# 代码审查计划

## 目标

只读分析 `CST-MDPS24120C-4TDP_V0.1.3` 固件，结合
`CST-MDPS24120C-4TDP_V1.0.pdf` 检查确定性 bug、产品风险和不完善之处。
不修改产品源码；改善建议以最小架构变动为原则，同时单列重大风险。

## 范围与约束

- 审查当前工作目录中的实际代码（包含用户现有未提交改动）。
- 第三方 HAL/CMSIS 仅检查项目配置和调用方式，不审查库内部实现。
- 不烧录设备、不改变硬件状态。
- 若规格或硬件行为无法由代码/PDF确认，列为待用户确认项。

## 阶段

1. [complete] 建立项目、构建配置和入口/中断/任务流概览
2. [complete] 提取 PDF 中与固件相关的功能、电气、时序和保护规格
3. [complete] 静态审查应用层、BSP、协议层及初始化/异常路径
4. [complete] 执行只读构建或静态检查（若环境可用）
5. [complete] 交叉验证发现，按严重度与确定性整理
6. [complete] 输出最小改动改善计划、重大风险和待确认问题

## 审查重点

- 越界、空指针、整数溢出、符号/单位/精度错误
- 中断与主循环共享数据、DMA/缓冲区生命周期、竞态
- SPI/UART 协议状态机、超时、CRC、重入、异常恢复
- ADC 标定/滤波/量程、触发控制、保护逻辑和故障闭锁
- Flash 掉电一致性、擦写寿命、参数校验和默认值
- 看门狗、HardFault/Error_Handler、启动和外设失败路径

## 错误记录

| 错误 | 尝试 | 处理 |
|---|---:|---|
| 初次组合命令退出码为 1 | 1 | `rg` 未找到规划/约束文件时返回 1；后续拆分检查。 |
| 系统未直接提供 `pdfinfo`/`pdftotext` | 1 | 改用 Codex 工作区内置 Python 与 PDF 库提取。 |
| PDF 文本首次输出遇到 GBK 不可编码字符 | 1 | 设置 `PYTHONIOENCODING=utf-8` 后成功提取。 |
