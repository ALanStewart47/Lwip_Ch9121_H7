# 发行记录

本文件仅记录已经正式交付的固件版本。日常开发修改请查阅 Git commit；当前工作状态请查阅 `STATUS.md`。

版本号与 Git tag 采用以下格式：`cst-mdps24120c-v<主>.<次>.<补丁>`。

## 尚未建立发布基线

当前仓库未发现此产品对应的 Git 发行 tag。维护者确认历史发布源码对应的版本后，应补充首个条目并创建同名 tag；在此之前，不应把当前工作目录直接宣称为可追溯的发布版本。
